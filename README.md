# الوجهة الأكاديمية - React

موقع فريق القيادة والمنظمين بـ React + Vite بنفس الستايل الأصلي.

## التشغيل

```bash
npm install
npm run dev
```

افتح الرابط اللي بيظهر (عادة http://localhost:5173)

## التعديلات المطبقة

- شيل محمد سينو من قسم المسؤولين
- حط مكانه **جون** (بدون روابط)
- حط **محمد سينو** في قسم فريق التنظيم
- حط **يامن حاجي محمود** في قسم البرمجة التنافسية
- حط **حسن زاهر** في قسم عرض البرمجيات
